# MonoSkillNavigator 新手教程

本教程面向第一次使用 MonoSkillNavigator 的 Skill 作者、使用者和团队管理员。完成后，你将能够浏览可信 Skill、查看审查结果、下载或收藏 Skill，并将自己的 Skill 发布到平台。

> **适用范围：** 本文以 Web 界面为主；CLI、API 和运维配置仅在需要时补充说明。

## 你将完成什么

1. 打开平台并注册或登录账户。
2. 在 Skill 广场搜索、筛选并查看一个 Skill。
3. 读懂版本状态、安全审查和 HaluCatch 质量评估。
4. 下载、收藏、评分或提交 Issue。
5. 准备并发布一个 Skill 包。
6. 发布新版本，以及管理自己发布的 Skill。

## 1. 认识页面和导航

顶部导航是日常操作的主要入口：

| 入口 | 用途 |
| --- | --- |
| **首页** | 查看热门 Skill、快速搜索和常用入口。 |
| **Skills** | 进入 Skill 广场，搜索、筛选、排序和发布 Skill。 |
| **Creators** | 查找发布者及其公开的 Skill。 |
| **榜单** | 按下载量、评分或更新时间浏览 Skill。 |
| **Audits** | 集中比较各 Skill 最新版本的审查数据，并导出报告。 |
| **文档** | 阅读 Skill 格式、发布流程、安全检测和质量审查说明。 |

登录后，点击右上角用户名可打开菜单：进入**个人中心**、修改密码、注销账户、添加 Skill、切换浅色/深色/跟随系统主题，或登出。

## 2. 注册、登录和个人中心

### 注册新账户

1. 点击右上角 **注册**，或访问 `/register`。
2. 填写用户名、邮箱、密码和确认密码。
3. 点击 **注册并登录**。
4. 成功后会自动进入你的 Creator 个人中心。

用户名必须为 3–64 个字符，只能包含字母、数字、点、下划线或连字符；密码至少 8 个字符。首个注册账户会成为管理员，后续账户默认为普通用户。

### 登录已有账户

1. 点击 **登录**。
2. 输入用户名和密码。
3. 点击 **登录**；成功后会跳转至个人中心。

### 使用个人中心

个人中心显示你的发布数量、下载量、平均评分和 Skill 列表。作为账户所有者，你还可以：

- 在 **Skills** 标签按名称、Slug 或描述筛选自己发布的 Skill；
- 在 **收藏** 标签快速回到已收藏的 Skill；
- 在 **回收站** 恢复误删的 Skill，或执行永久删除；
- 通过左侧的 **修改密码**、**注销账户** 和 **登出** 管理账户。

> **谨慎操作：** 注销账户需要再次输入当前密码并确认；账户、已发布 Skill、收藏和登录状态都会被永久删除，无法恢复。

已拒绝或已下架的 Skill 仅对其拥有者显示在个人中心，不会出现在公开 Skill 广场或搜索结果中。

## 3. 浏览、搜索和筛选 Skill

1. 点击顶部 **Skills** 进入 Skill 广场。
2. 在搜索框输入 Skill 名称、发布者或描述中的关键词；也可以在首页搜索后直接跳转到此页面。
3. 点击分类标签进行筛选，最多可同时选择 3 个分类。
4. 未输入关键词时，可用右侧排序选择 **New**、**Rating** 或 **Trending**。
5. 点击任一 Skill 卡片，进入该 Skill 的详情页。

搜索时排序控件会暂时禁用，因为结果按匹配度返回；清空搜索词后即可再次使用排序。

- 在 **Creators** 页面搜索发布者名称或 `@用户名`，点击发布者可进入其公开主页。
- Creator 主页会展示公开的 Skill、下载量和评分；只有本人能看到收藏、回收站及被隐藏的内容。

## 4. 在详情页判断 Skill 是否适合使用

点击某个 Skill 后，先查看页面顶部的关键信息：

- **状态徽章：** `已发布`、`需复核` 或 `已拒绝`；
- **Slug 与版本号：** `slug` 是稳定的唯一标识，版本号对应当前查看的不可变内容；
- **评分、下载量和开放 Issue 数：** 反映社区使用和反馈情况；
- **分类：** 帮助判断用途；
- **当前查看版本：** 显示版本、文件数、版本数、Issue 与评分统计。

状态代表审查结果，而不是“好用程度”的单一总分：

| 状态 | 建议动作 |
| --- | --- |
| **已发布** | 审查流程完整且没有 finding；仍应阅读 Skill 内容与权限声明。 |
| **需复核** | 已保存，但存在需要人工判断或改进的 finding；先查看“审查与评估”。 |
| **已拒绝** | 命中自动拒绝规则；不要安装或推广，作者应修复后发布新版本。 |

![图 08：Skill详情](../../public/docs/tutorial/08-skill-detail-overview.png)
*图 08：Skill详情*

### 了解详情页的六个内容标签

| 标签 | 用途 |
| --- | --- |
| **SKILL.md** | 阅读 Skill 的原始说明、步骤和边界。 |
| **Skill Card** | 查看作者、许可证、支持的 Agent、允许/禁止的工具与贡献者。 |
| **Files** | 浏览归档中的文本文件及其内容哈希。 |
| **Versions** | 选择历史版本，查看 Changelog，并下载特定版本。 |
| **审查与评估** | 查看安全 finding、VirusTotal 摘要和 HaluCatch 质量结果。 |
| **Issue 与评分** | 查看或提交问题、为当前版本评分。 |

### 下载、复制安装说明和收藏

- **下载 Skill：** 需要登录。点击 **下载 Skill** 获取当前 `latest` 版本 ZIP；在 **Versions** 中也可下载某个历史版本。
- **复制 prompt：** 会复制一段供 AI 助手执行安装的说明；使用前先自行确认 Skill 的权限和审查结果。
- **收藏：** 登录后点击 **收藏**，它会出现在个人中心的“收藏”标签中。

> 平台只对 Skill 包做静态解析与审查，**不会执行包内脚本**。下载或让其他 Agent 安装前，仍应根据团队的权限政策进行复核。

## 5. 查看安全审查和质量评估

在详情页点击 **审查与评估**，建议按以下顺序阅读：

1. **先看状态徽章**：确认是已发布、需复核还是已拒绝。
2. **查看 HaluCatch 质量评估**：五维雷达展示地基与数据管线、代码风险、规则与方法论、解读护栏、复杂度与可维护性；若出现 **查看完整报告** 按钮，可阅读专业版、标准版或行动版报告。
3. **查看安全审查**：SkillSpector 摘要给出安全分、包级风险、安装建议和扫描模式；下方 finding 会给出严重度、置信度、证据和修复建议。
4. **查看 VirusTotal 摘要（如已配置）**：确认扫描状态、恶意/可疑检出数、参与引擎数和报告链接。

安全分和 HaluCatch 质量结果分别服务于不同目的，不能简单相加为“总分”。完整解释见[安全检测](./security-scan.md)和[质量审查](./halucatch-review.md)。

## 6. 提交 Issue 和评分

登录后，在 **Issue 与评分** 标签中可以参与反馈：

### 提交 Issue

1. 点击 **提交 Issue**。
2. 选择类型：`bug`、`security`、`compatibility`、`feature` 或 `docs`。
3. 选择严重程度，填写标题；详情可补充复现步骤、影响范围或建议。
4. 点击 **确认提交**。

### 提交评分

1. 点击 **提交评分**。
2. 选择 1–5 星，可选填评论。
3. 点击 **确认提交**。

每位用户对同一个 Skill 的同一版本只能评分一次；切换到另一个版本后可以单独评分。

## 7. 准备要发布的 Skill 包

每个 Skill 必须包含 `SKILL.md`（也兼容 `skill.md` 与 `skills.md`），可直接上传文件夹或 ZIP。推荐结构如下：

```text
my-skill/
  SKILL.md
  references/       # 可选
  examples/         # 可选
  scripts/          # 可选；只会被静态扫描，不会执行
```

在 `SKILL.md` 的 YAML frontmatter 中，至少准备 `name`、`description` 和合法的 `version`。通过 Web 发布新 Skill 时，还需要确保：

- `slug` 是唯一的、小写 kebab-case 标识，例如 `github-issue-triage`；
- 至少选择一个分类，最多 3 个；
- 版本符合 SemVer，例如 `1.0.0`；
- release tag 通常填写 `latest`。

具体字段和示例请先阅读 [Skill 格式](./skill-format.md)。

## 8. 通过 Web 发布第一个 Skill

### 进入发布页并上传

1. 登录后，在 **Skills** 页面点击 **Publish**；也可打开右上角用户菜单并选择 **添加 Skill**。
2. 在上传区任选一种方式：
   - 点击 **选择文件夹**；
   - 点击 **选择 .zip**；
   - 将文件夹或 ZIP 拖拽到上传区。
3. 上传后，页面会解析 Skill 入口文件，并尽量自动填写 frontmatter 中的字段。

![图 12：Skill上传与发布](../../public/docs/tutorial/12-publish-upload.png)
*图 12：Skill上传与发布*

### 检查并补全发布信息

解析完成后，检查下列字段：

| 字段 | 操作说明 |
| --- | --- |
| **Display Name** | 面向用户显示的名称。 |
| **Slug** | 新 Skill 的唯一 ID；发布后不能修改。若已存在且你有权限，平台会提示将作为新版本发布。 |
| **Description** | 清楚说明 Skill 能做什么、适用于什么场景。 |
| **Categories** | 必填，选择 1–3 个用于搜索的分类。 |
| **Topics** | 可选，用逗号分隔业务主题或自定义标签。 |
| **Version** | 必填，采用 SemVer；新版本必须高于当前最新版本。 |
| **Release Tags** | 必填，用逗号分隔；常用值为 `latest`。 |
| **Changelog** | 仅发布新版本时可选，用于说明新增、修复或不兼容变更。 |

确认无误后点击 **发布 Skill**。若按钮不可用，先阅读表单下方的提示，例如未登录、Slug 无权限、分类未选、版本冲突或格式不正确。

### 理解发布结果

点击发布后，平台会运行格式校验、SkillSpector 静态安全审查、可选 VirusTotal 扫描和 HaluCatch 质量评估。

- **成功完成：** 页面返回个人中心，并提示 `已发布`、`需复核` 或 `已拒绝`。打开该 Skill 详情即可查看记录。
- **审查流程未完成：** 如 VirusTotal、SkillSpector 或 HaluCatch 的已启用步骤无法完成，Skill **不会保存**。页面会列出失败步骤，可在恢复环境后点击 **重新运行完整审查**，无需重新选择文件。
- **已拒绝：** 版本已经保存，但不会在公开搜索、榜单或其他发布者页面出现；拥有者可在个人中心和详情页查看 finding、修复问题并发布递增的新版本。

更多规则和常见失败原因见[发布流程](./publish-workflow.md)。

## 9. 发布新版本与管理已发布 Skill

### 发布新版本

Skill 所有者或 contributor 可在详情页右侧点击 **发布新版本**：

1. 页面会带入当前 Skill 的名称、Slug、分类和建议的下一个补丁版本。
2. 上传更新后的文件夹或 ZIP。
3. 保持原 Slug，填写高于当前版本的新 SemVer，例如从 `1.0.0` 改为 `1.0.1`。
4. 填写 Changelog，说明变化。
5. 点击 **发布新版本**，等待重新审查。

同一 `slug@version` 的内容不可覆盖；修复问题必须提高版本号并重新发布。

### 添加 contributor

只有 Skill owner 可以在详情页的 **Skill Card** 标签中添加 contributor：

1. 输入一个已注册的平台用户名。
2. 点击 **添加 contributor**。
3. 新成员可以协助发布新版本，但不能添加 contributor 或变更 owner。

![图 13：审查中心](../../public/docs/tutorial/15-skill-card.png)
*图 13：审查中心*

### 下架、上架和删除

只有 owner 可以操作：

- **下架：** 从 Skill 广场、榜单和公开搜索中隐藏；之后可点击 **上架** 恢复。
- **下架历史版本：** 在 **Versions** 中对非最新版本操作；最新版本不能单独下架。
- **删除：** 先移入回收站，默认保留 3 天；可在个人中心恢复，或立即永久删除。

## 10. 在审查中心对比和导出数据

需要集中查看多个 Skill 的审查情况时：

1. 打开顶部 **Audits**。
2. 使用排序字段比较发布时间、SkillSpector 安全分或 HaluCatch 分数。
3. 勾选需要导出的记录；全选会选择所有 Skill。
4. 点击 **导出 CSV** 或 **导出 Excel**。
5. 在确认弹窗中确认导出。

审查中心展示的是每个 Skill 的最新版本概要；需要定位具体 finding 时，点击表格中的 Skill 名称进入详情页。

## 常见问题

### 为什么看不到刚发布的 Skill？

先查看个人中心与详情页的状态：

- `已拒绝` 或已下架的 Skill 不会公开显示；
- `需复核` 已保存，但应先处理 finding；
- 审查流程未完成时，Skill 根本没有保存，需要从发布页重试。

### 为什么不能下载、收藏、评分或提交 Issue？

这些操作需要登录。下载只对已上架的版本开放；评分对同一用户、同一版本仅允许一次。

### 为什么不能发布到已有的 Slug？

只有 owner 或 contributor 能为已有 Skill 发布新版本；其他用户应创建新的唯一 Slug，或联系 owner 添加 contributor。

### 为什么没有 HaluCatch 雷达或完整安全信息？

这通常表示运行环境未配置相应服务，或发布时评估使用了回退模式。普通用户可联系管理员；作者仍应检查 `SKILL.md`、权限声明和包内文件，并重新发布新版本以生成新的报告。
